# Литания

Английский с нуля для одного ученика и одного учителя. Фразы, карточки с интервальными повторениями (FSRS-6), игры на слух, три коротких занятия в неделю. Оформление по мотивам Warhammer 40,000.

Открыть: https://dmitrykulakovfrontend.github.io/litania/

- `/` страница ученика, `/#7` она же на неделе 7
- `/?teacher` страница учителя
- `/?demo` и `/?demo#him5` демо с заполненной историей

Сборки нет, зависимостей нет: статические файлы, открываются как есть. После первого визита работает без интернета.

## Разработка

```
node tools/serve.mjs                 # http://localhost:5290/litania/
node tools/offline-test.mjs          # офлайн, входные ссылки, консоль
node tools/sw.mjs                    # перед публикацией: список файлов и версия для офлайна
node tools/icons.mjs                 # иконки из эмблемы
node tools/fonts.mjs                 # шрифты с кириллицей, один раз
```

Арт из вселенной Warhammer 40,000 принадлежит Games Workshop и её художникам. Это личный некоммерческий проект.
